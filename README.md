# TechStore — Vitrine demonstrativa

Site estático desenvolvido para a disciplina de **Desenvolvimento Web I (2025)**, utilizando **HTML5 e CSS3**, com vitrine de produtos de informática.

## Executar

Clone ou baixe o repositório e abra o arquivo `index.html` em um navegador:

```bash
git clone https://github.com/Dhaniels1/TechStore.git
cd TechStore
```

Não é preciso instalar pacotes, iniciar backend nem configurar banco de dados.

## Funcionalidades

- Cabeçalho com navegação para seções reais da página.
- Apresentação do projeto e acesso à vitrine.
- Cartões de três produtos com imagens, descrições e preços ilustrativos.
- Layout responsivo para celular e computador.
- Links externos seguros para o repositório.

## Estrutura

```text
TechStore/
├── index.html       # Estrutura e conteúdo
├── css/
│   └── style.css    # Estilos e regras responsivas
└── img/             # Imagens dos produtos
```

## Natureza do projeto

**Este site não é uma loja operacional:** não há carrinho, pagamentos, estoque, login nem integração com pedidos. Os preços e produtos são apenas exemplos de uma atividade acadêmica.

Na revisão de outubro de 2026, o HTML ganhou elementos semânticos, descrições de imagens, navegação funcional por âncoras, melhorias de acessibilidade e estilos responsivos. Os botões "Comprar" sem funcionalidade foram substituídos por avisos claros de demonstração.
