# TechStore — Vitrine demonstrativa

Site estático desenvolvido para a disciplina de **Desenvolvimento Web I (2025)**, utilizando **HTML5 e CSS3**, com vitrine de produtos de informática. Em outubro de 2026, o projeto ganhou uma reformulação de interface com visual escuro, destaque editorial, cartões de produtos e melhor experiência em dispositivos móveis.

## Executar

Clone ou baixe o repositório e abra o arquivo `index.html` em um navegador:

```bash
git clone https://github.com/Dhaniels1/TechStore.git
cd TechStore
```

Não é preciso instalar pacotes, iniciar backend nem configurar banco de dados.

## Funcionalidades

- Cabeçalho escuro com navegação para seções reais da página e indicação de projeto demonstrativo.
- Hero com tipografia destacada e ilustração construída em CSS, sem bibliotecas de JavaScript.
- Cartões de três produtos com imagens, descrições, preços ilustrativos e rótulos de demonstração.
- Layout responsivo com nova paleta azul-marinho e turquesa, incluindo dispositivos móveis.
- Links externos seguros para o repositório.

## Estrutura

```text
TechStore/
├── index.html       # Estrutura e conteúdo
├── css/
│   └── style.css    # Estilos e regras responsivas
└── img/             # Imagens dos produtos
```

## Natureza do projeto

**Este site não é uma loja operacional:** não há carrinho, pagamentos, estoque, login nem integração com pedidos. Os preços e produtos são apenas exemplos de uma atividade acadêmica.

Na revisão de outubro de 2026, o HTML ganhou elementos semânticos, descrições de imagens, navegação por âncoras, melhorias de acessibilidade e uma nova linguagem visual. O projeto permanece estático e não possui compras online. Os botões "Comprar" sem funcionalidade foram substituídos por avisos claros de demonstração.
